# Дафтар — личный бюджет и планерка

Веб-платформа на одном HTML-файле. Без сервера, без сборки, без зависимостей.
Данные хранятся в браузере и выгружаются в JSON или CSV.

**Демо:** https://isosaid.github.io/daftar/

## Возможности

**Бюджет**
- Несколько бюджетов: личный, семейный, проектный — свои конверты и операции у каждого
- Конверты (статьи расходов) со своим лимитом, цветом и названием — добавляются и меняются
- Три типа операций: доход, расход, «в цель» (откладывание — отдельная строка, не расход)
- Перенос остатка на следующий месяц — включается переключателем
- Любой месяц можно начать с нуля или с нужной суммы, не трогая прошлые
- Всё редактируется в один клик: операция, задача, цель, конверт, лимит
- Накопительные цели: сколько накоплено, сколько осталось, нужный взнос в месяц

**Планерка**
- Недельная лента пн—вс с задачами по дням
- Задача: модуль, исполнитель, срок, статус (открытый / в работе / приостановлен / завершён)
- Просрочка считается автоматически

**Отчёты**
- Расходы по месяцам за полгода
- План и факт по конвертам
- Сравнение бюджетов за месяц
- Задачи по модулям

## Вход и синхронизация

Регистрация по почте и паролю, чтобы бюджет открывался и на компьютере, и на телефоне.
Настройка — 5 минут, см. [FIREBASE.md](FIREBASE.md). Пока ключи не вписаны,
платформа работает без входа: данные сохраняются в одном браузере.

Каждый пользователь видит только свои данные — это закреплено правилами доступа
на стороне базы, а не только в интерфейсе.

## Запуск

Скачайте `index.html` и откройте двойным кликом. Всё.

## Публикация на GitHub Pages

1. Settings → Pages
2. Source: Deploy from a branch
3. Branch: `main`, папка `/ (root)` → Save

Через минуту сайт открывается по адресу `https://<ваш-логин>.github.io/daftar/`.

## База данных

| Файл | Что это |
|------|---------|
| `data/empty.json` | Чистая база: ноль записей и ноль конвертов |
| `DATABASE.md` | Структура и формулы расчётов |
| `config.js` | Ключи Firebase для входа |
| `FIREBASE.md` | Пошаговая настройка входа |

Приложение всегда стартует с пустой базы: ни операций, ни задач, ни конвертов.
Конверты создаются по кнопке — по одному или готовым набором из 7 статей.
Чтобы загрузить свой файл: Настройки → Данные → «Загрузить копию».
Ключ хранения — `daftar-v3`.

## Резервная копия

Настройки → «Скачать копию» — файл `daftar-ГГГГ-ММ-ДД.json`.
Тот же файл открывается на другом устройстве через «Загрузить копию».
`Операции в CSV` — выгрузка для Excel по всем бюджетам сразу.

## Стек

Ванильный HTML, CSS и JavaScript. Шрифты Bitter, Golos Text, IBM Plex Mono.
Никаких фреймворков и внешних библиотек.
