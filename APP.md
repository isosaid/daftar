# Установка на телефон

## Android

1. Открыть https://isosaid.github.io/daftar/ в **Chrome**
2. Меню `⋮` → **Установить приложение** (или всплывёт баннер внизу)
3. Иконка появится на главном экране

Открывается на весь экран, без адресной строки. Работает без интернета —
записи сохранятся и уйдут в облако, когда связь вернётся.

## iPhone и iPad

1. Открыть https://isosaid.github.io/daftar/ в **Safari** (именно в нём, Chrome на iOS не умеет)
2. Кнопка «Поделиться» внизу → **На экран «Домой»**
3. Название `Дафтар` → **Добавить**

## Настоящий APK-файл

Если нужен именно файл `.apk` — для установки без магазина или для публикации
в Google Play:

1. Открыть https://www.pwabuilder.com
2. Вставить адрес `https://isosaid.github.io/daftar/` → **Start**
3. Раздел **Android** → **Generate Package**
4. Скачается архив: внутри `app-release-signed.apk` для установки
   и `.aab` для загрузки в Google Play

Сервис бесплатный, от Microsoft. Он берёт манифест и оболочку сайта
и упаковывает в приложение.

**Для iOS так не получится.** Apple не позволяет ставить приложения мимо App Store.
PWABuilder умеет собрать проект для Xcode, но для публикации нужен
аккаунт разработчика Apple — 99 долларов в год. Установка «На экран Домой»
даёт то же самое бесплатно.

## Что даёт установка

| | В браузере | Установленное |
|---|---|---|
| Адресная строка | занимает место | нет |
| Иконка на экране | нет | есть |
| Работа без интернета | нет | есть |
| Открывается | через закладку | как приложение |

Данные одни и те же — вход по той же почте, синхронизация через Firebase.

## Обновления

Приложение обновляется само при запуске с интернетом. Если версия
«застряла» — закрыть приложение полностью и открыть заново.
